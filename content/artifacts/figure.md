# Figure

`<Figure>` renders an image with alt text and an optional caption. Use it for screenshots and static visuals when a programmable artifact like `<Diagram>` or `<FlowMap>` is unnecessary.

- Component: `app/components/mdx/Figure.tsx`
- Props:
- `src`: image path, usually under `public/images/`
- `alt`: required description for the image
- `caption`: optional supporting text
- When to use: for screenshots, exported diagrams, and visuals that need a caption
