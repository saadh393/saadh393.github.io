# Tabs

`<Tabs>` lets the reader switch between a few versions of the same idea without scrolling through every variant. Use it when code, config, or framework examples share the same purpose but differ in syntax.

- Component: `app/components/mdx/Tabs.tsx`
- Props:
- `<Tabs>` takes `children` and optional `defaultTab`
- `<Tab>` takes `label` and `children`
- When to use: for multi-language snippets, framework variants, and environment-specific config
