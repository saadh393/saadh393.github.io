# Accordion

`<Accordion>` hides supporting detail until the reader asks for it. Use it when extra context is useful but would interrupt the main narrative if it stayed open all the time.

- Component: `app/components/mdx/Accordion.tsx`
- Props:
- `<Accordion>` takes `children`
- `<AccordionItem>` takes `title`, `children`, and optional `defaultOpen`
- When to use: for FAQs, objections, trade-off notes, and optional deep dives
